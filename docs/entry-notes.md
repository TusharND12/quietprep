## Development evidence

The setup script pins model revisions and the runtime archive and verifies SHA-256 hashes. The recommended model is Qwen3-4B-Instruct-2507 (LM Studio Community quantization); the compact option uses official Qwen2.5-1.5B weights. Regression tests exercise input validation, cross-site requests, local model restrictions, malformed model responses, invented evidence IDs, retry context, word changes, and concurrency. The browser check exercises actual local inference and saves synthetic results and screenshots under `artifacts/`. [The evaluation](evaluation.md) publishes both models' responses, including poor coaching from the compact model.

These are software checks, not a user study. Claims about the beneficiary's experience require their own real test.
