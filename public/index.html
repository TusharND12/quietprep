Open weights. A quieter kind of AI.

A little setup. Then it’s yours.

QuietPrep uses an open-weight model running on your own computer. Download it once; then practise without an internet connection.

Linux: start everything together

From the project folder, with Python 3.11 or later:

python3 scripts/setup_local.py
python3 scripts/run_local.py

First setup downloads about 1.14 GB. No GPU required.

Already using Ollama?

ollama pull qwen2.5:1.5b
ollama serve
# In another terminal:
python3 server.py

Use this option instead of the bundled runner. If Ollama is already running, skip ollama serve.

No cloud fallback, API key, analytics, or automatic answer storage. Local model software may have its own logging settings. You control when to export notes.
